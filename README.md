<h1 align="center">
    Age of War Reimagined
</h1>

This project is a recreation of the classic flash game **Age of War**. <br />
The goal of this project is add multiplayer and inovate on to the original game with new units, factions and similar features.

## Documentation

## Plugins
- [NodeTunnel](https://github.com/curtjs/nodetunnel)

## Installing and running
1. Clone the repository: `git@github.com:AndrejGockov/moeraspolozenie.mk.git`
2. Open in Godot
3. Run the project `F5`
